# Student-Placement-Prediction-Logistic-Regression
A Machine Learning project that predicts student placement outcomes using Logistic Regression with Python and Scikit-learn.

# Student Placement Prediction using Logistic Regression

## Project Overview
This project uses Machine Learning to predict whether a student will get placed or not based on different student-related features.

The project implements the **Logistic Regression** classification algorithm using Python and Scikit-learn.

## Objectives
- Understand and implement Logistic Regression.
- Perform data exploration and preprocessing.
- Train and test a classification model.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Workflow
1. Import required libraries.
2. Load and explore the dataset.
3. Perform data preprocessing.
4. Select input features and target variable.
5. Split the dataset into training and testing sets.
6. Train the Logistic Regression model.
7. Make predictions.
8. Evaluate the model using a Confusion Matrix, Classification Report, and ROC-AUC Curve.

## Model Evaluation
The model is evaluated using classification metrics and an ROC Curve to understand its prediction performance.

## Conclusion
This project helped me gain practical knowledge of Logistic Regression, classification problems, and machine learning model evaluation.
